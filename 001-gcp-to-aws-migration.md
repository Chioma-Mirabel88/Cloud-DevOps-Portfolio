# Project 001: GCP to AWS Migration Project

## Overview

Supported the migration of a production loan application from Google Cloud Platform (GCP) to Amazon Web Services (AWS) as part of the organization's cloud standardization initiative.

## Business Problem

The organization sought to standardize its cloud infrastructure on AWS and leverage AWS services to support future business growth and credit issuance requirements.

## Existing GCP Architecture

The application was hosted on Google Cloud Platform and consisted of:

* Frontend application running on Google Compute Engine (GCE)
* Backend services running on GCE
* Cloud SQL PostgreSQL database
* Cloud Storage for object and file storage
* Cloud Pub/Sub for asynchronous messaging and notifications
* Third-party integrations for payment processing, banking services, and verification platforms

## Target AWS Architecture

The migration introduced AWS-native services including:

* AWS Amplify for frontend deployment
* Amazon ECS Fargate for containerized workloads
* Amazon RDS for PostgreSQL database services
* Amazon S3 for object and file storage
* Amazon ECR for container image management
* Amazon SNS for notifications and messaging

As a Cloud/DevOps Engineering Intern, I contributed to:

* Environment validation and testing
